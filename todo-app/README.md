# 🎀 Retro To-Do App

A cute, retro-inspired To-Do List built with React and JavaScript, featuring a pastel pink and blue gingham aesthetic.

## ✨ Features
- Add and edit tasks using a reusable form
- Delete tasks
- Mark tasks as Pending or Completed
- Responsive retro-style UI

## 🛠️ Tech Stack
- React
- JavaScript
- Vite
- CSS

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📌 Note
Tasks are stored in React state and reset when the page is refreshed.
